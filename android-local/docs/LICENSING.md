# Licensing and provenance notes

This Android import does not add a repository-wide license or relicense upstream material.

During preparation on 2026-10-30, the checked LocalArknights baseline contained no LICENSE/COPYING/NOTICE file, and GitHub reported no detected upstream license. No separate permission from the upstream author was supplied. Do not describe the whole codebase as MIT-, GPL- or otherwise uniformly open-source-licensed solely because this fork is public.

The repository owner explicitly selected publication into this public fork. Visibility and an open-source license are separate matters. Existing upstream/third-party rights, notices and applicable terms remain in force. No new general license grant is made here for the Android changes.

Dependencies retain their own licenses. Obtain and retain the relevant notices from official distributions when building or redistributing software containing them. The compile helper downloads dependencies locally and does not publish their binaries.

Game client/assets, accounts, saves, private configuration, TLS keys and signing material are absent from the Android import. Pre-existing upstream files and Git history remain preserved; this document is scoped to the added Android source tree.
